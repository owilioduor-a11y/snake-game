# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-24

### Added
- Initial release of Snake Combo game
- Classic snake gameplay mechanics
- Combo system for multiplied scores
- Three difficulty levels (Easy, Medium, Hard)
- Achievement system with 8 unlockable achievements
- Responsive design for desktop, tablet, and mobile
- Touch controls with swipe gestures
- Keyboard controls (Arrow keys, WASD)
- Mouse click controls
- Visual effects (particles, screen shake, combo animations)
- Procedural sound effects using Web Audio API
- Local storage for persistent high scores and game data
- Settings menu for customization
- Pause functionality
- Game over screen with statistics
- Start screen with game statistics
- Modern, polished UI with CSS3 animations

### Features
- High score tracking per difficulty level
- Total games played counter
- Total score accumulator
- Best combo tracking
- Sound toggle
- Screen shake toggle
- Particle effects toggle
- Data reset functionality
- Canvas-based rendering
- Responsive grid sizing for different screen sizes
- Mobile-optimized layout
